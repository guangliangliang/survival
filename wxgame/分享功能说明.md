# 微信小游戏分享功能说明

## 已实现的功能

### 1. 基础分享配置

在 `game.js` 中已添加：

- 自动显示分享菜单（右上角转发和分享到朋友圈）
- 配置默认分享信息（游戏名称：边境守夜人）
- 提供主动分享的 API

### 2. ShareHelper 工具类

新增 `share-helper.js`，提供更完善的分享功能：

- 灵活配置分享标题、图片、参数
- 主动触发分享的方法
- 更新分享菜单的方法

## 使用方法

### 方式一：使用已配置的基础功能（推荐）

游戏启动时会自动配置分享功能，用户可通过右上角菜单分享。

### 方式二：在 Godot 中调用分享

在 Godot 脚本中通过 JavaScript 接口调用：

```gdscript
# 主动触发分享给好友
JavaScript.eval("GameGlobal.shareGame()")

# 或者使用 ShareHelper
JavaScript.eval("GameGlobal.ShareHelper.shareToFriend()")

# 修改分享配置
JavaScript.eval("GameGlobal.ShareHelper.setShareConfig({title: '新标题', imageUrl: 'images/new.png'})")
```

## 注意事项

### 1. 开发者工具限制

- 在微信开发者工具中，分享功能可能无法完整测试
- 建议使用真机调试来测试完整的分享流程
- 开发者工具中点击右上角转发可能没有反应是正常的

### 2. 分享图片要求

- 图片大小不能超过 500KB
- 建议使用 5:4 比例的图片
- 图片路径必须是本地资源或网络图片

### 3. 分享参数

- query 参数用于传递分享信息
- 可以通过 query 参数追踪分享来源

## 常见问题

### Q: 为什么在开发者工具中点击转发没反应？

A: 这是正常现象。微信开发者工具的分享功能有限制，请使用真机调试测试。

### Q: 如何自定义分享内容？

A: 可以通过修改 `game.js` 中的 `shareConfig` 或调用 `ShareHelper.setShareConfig()` 方法。

### Q: 分享失败怎么办？

A: 请检查：

1. 图片是否存在且大小符合要求
2. 小程序 AppID 是否正确配置
3. 是否在微信公众平台配置了相关权限

## 相关文件

- `game.js` - 主入口文件，包含基础分享配置
- `share-helper.js` - 分享功能增强工具类
